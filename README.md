## منهجية التوثيق

كل غرفة موجودة داخل مجلد مستقل مرقّم للحفاظ على ترتيب الإنجاز وسهولة القراءة. يبدأ ملف `README.md` بملخص قابل للقراءة السريعة، ثم يربط بملف `solution.md` للحل المتسلسل وملف `notes.md` للملاحظات والأدلة. لا تُضاف الغرفة إلى الفهرس إلا بعد ظهور الإجابة الصحيحة أو حالة الإكمال الرسمية داخل TryHackMe وفق ما تم توثيقه.

## سير العمل للغرف القادمة

عند حل غرفة جديدة، تُضاف بعد التحقق الرسمي إلى مجلد مستقل بالصيغة نفسها: معلومات الغرفة، الهدف، التحليل، خطوات الحل، الإجابات، دليل التحقق، والدروس الأمنية. الغرف التي لم يثبت إكمالها رسمياً تبقى خارج الفهرس إلى أن تكتمل.

## ملاحظة الخصوصية

المستودع منشأ كـ **Private repository**. لا تُضاف إليه بيانات الحسابات أو الرموز السرية أو معلومات خارج نطاق المختبر، وتُستخدم عناوين IP المؤقتة فقط عندما تكون جزءاً من شرح المختبر.
