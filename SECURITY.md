# Security Policy

## Supported Versions

The default branch is the supported version.

## Responsible Use

This repository contains Arabic write-ups and solutions for **authorized** TryHackMe rooms only. The content is intended for educational purposes within the official TryHackMe platform and legal learning environments.

Do not use any information here against systems you do not own or lack explicit permission to test.

## Reporting Issues

For security-related concerns about this documentation repository, contact the owner through the GitHub profile at https://github.com/9gkc. Please avoid posting sensitive details in public issues.
