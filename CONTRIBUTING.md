# Contributing to the TryHackMe Write-ups

Thank you for your interest in improving these educational notes.

## Scope

This repository contains Arabic write-ups for **authorized** TryHackMe rooms only. Contributions must remain educational and must not encourage testing against systems without explicit permission.

## Standards

- Keep explanations clear and responsible
- Do not add payloads or techniques intended for unauthorized use
- Prefer accuracy and clarity over completeness
- Keep technical documentation in English when adding new files

## Security

Follow the process in [SECURITY.md](SECURITY.md).
