## Key Concepts Covered

The room covered the distinction between **IaaS, PaaS, and SaaS**, the difference between **security of the cloud** and **security in the cloud**, the shared responsibility model, cloud migration pitfalls, logging limitations, SIEM integration challenges, and monitoring of cloud workloads. It also introduced cloud security tools such as **CWPP**, **CSPM**, and **CASB**.
