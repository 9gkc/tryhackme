## ملخص المسار

يستخدم التطبيق Next.js وReact Server Components. أدى استغلال ثغرة React2Shell المرتبطة بـ `CVE-2025-55182` إلى تنفيذ أوامر عن بُعد على الخادم ضمن سياق المستخدم `daniel`.[1] [2]

بعد الحصول على تنفيذ الأوامر، تمت قراءة علم المستخدم من `/home/daniel/user.txt`. ثم كشف الأمر `sudo -l` أن المستخدم يستطيع تشغيل `/usr/bin/python3` بامتيازات root مع `NOPASSWD`. استُخدم ذلك لتشغيل Python وفتح صدفة root، ثم قراءة `/root/root.txt`.

## خطوات الحل

### 1. الوصول إلى RCE

تم استغلال نقطة الضعف في معالجة React Server Components للحصول على تنفيذ أوامر على الخادم. نتج عن ذلك سياق تنفيذ باسم `daniel`.

### 2. قراءة علم المستخدم

بعد الوصول إلى الصدفة، تمت قراءة الملف:

```text
cat /home/daniel/user.txt
```

والعلم المقبول هو:

```text
THM{R34c7_2_5h311_3xpl017}
```

### 3. فحص صلاحيات sudo

أظهر فحص الصلاحيات أن `/usr/bin/python3` يمكن تشغيله كـ root دون كلمة مرور. هذه القاعدة واسعة بما يكفي لتسمح بتنفيذ أوامر نظام بصلاحيات root.

### 4. التصعيد إلى root

تم استخدام Python لتشغيل صدفة بصلاحيات root، ثم تمت قراءة الملف:

```text
cat /root/root.txt
```

والعلم المقبول هو:

```text
THM{Pr1v_35c_47_175_f1n357}
```
