## الهدف

تطلب الغرفة استغلال تطبيق ويب مبني على Next.js وReact Server Components، ثم الانتقال من تنفيذ الأوامر على حساب التطبيق إلى صلاحيات root وقراءة علمَي المستخدم وroot.

## الملاحظات التقنية

يعمل التطبيق على المنفذ 3000 ويستخدم React Server Components. تم استغلال ثغرة React2Shell المرتبطة بـ `CVE-2025-55182` للحصول على تنفيذ أوامر عن بُعد ضمن سياق المستخدم `daniel`.

بعد الوصول إلى الصدفة، تمت قراءة علم المستخدم من:

```text
/home/daniel/user.txt
```

وأظهر فحص صلاحيات sudo أن المستخدم `daniel` يستطيع تشغيل `/usr/bin/python3` كـ root دون كلمة مرور. يسمح ذلك بتنفيذ Python لفتح صدفة بصلاحيات root، ثم قراءة:

```text
/root/root.txt
```
