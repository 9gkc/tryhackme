## الملخص التنفيذي

يستعرض هذا المختبر تطبيقاً مبنياً على Next.js ويستخدم React Server Components. تم استغلال ثغرة React2Shell المرتبطة بـ CVE-2025-55182 للحصول على تنفيذ أوامر عن بُعد على الخادم ضمن سياق المستخدم daniel [1] [2]. بعد ذلك، جرى استخراج علم المستخدم من مسار المنزل، ثم تم اكتشاف إمكانية تشغيل Python3 بامتيازات root عبر sudo دون كلمة مرور، ما أتاح ترقية الامتيازات والوصول إلى علم root.

الهدف النهائي تمثل في إثبات أثر الجمع بين ثغرة RCE في طبقة الويب وقاعدة sudo واسعة الصلاحيات، عبر قراءة علمَي المستخدم وroot المؤكدَيْن داخل المنصة.

## مسار الحل

### 1. الوصول إلى RCE

استُغلت ثغرة في معالجة React Server Components (React2Shell المرتبطة بـ CVE-2025-55182) للحصول على تنفيذ أوامر على الخادم، وأُثبت السياق بأنه ضمن حساب النظام daniel.

### 2. قراءة علم المستخدم

بعد الحصول على الصدفة، جرى قراءة ملف العلم:

```text
cat /home/daniel/user.txt
```

العلم المقبول:
```text
THM{R34c7_2_5h311_3xpl017}
```

### 3. فحص صلاحيات sudo

تم التحقق من صلاحيات sudo للمستخدم daniel، وأظهر الفحص إمكانية تشغيل Python3 كـ root دون كلمة مرور:

```text
sudo -l
```

أتاحت قاعدة NOPASSWD المرتبطة بـ /usr/bin/python3 تنفيذ أوامر نظام بامتيازات مرتفعة.

### 4. التصعيد إلى root وقراءة العلم

استُخدم Python لتشغيل صدفة بصلاحيات root، ثم تمت قراءة العلم:

```text
cat /root/root.txt
```

العلم المقبول:
```text
THM{Pr1v_35c_47_175_f1n357}
```

## الدروس الأمنية

- تصحيح سريع للمكوّنات المعرضة لثغرات RCE في الأطر الحديثة مثل React Server Components أمر حاسم.
- يجب تقييد قواعد sudo، وتجنّب NOPASSWD للأوامر العامة مثل /usr/bin/python3، أو حصرها بأوامر وآليات أكثر أماناً.
- الدمج بين ضعف على طبقة التطبيق وقاعدة امتيازات محلية واسعة يؤدي إلى سيطرة كاملة على النظام؛ الدفاع العميق وتقليل الامتيازات يحدّان من الأثر.
